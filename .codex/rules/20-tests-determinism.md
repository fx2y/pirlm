# Test + Determinism Rules

- `T0` Determinism mandatory: no live network/oracle, no wall-clock assertions, no unseeded randomness, no locale/TZ coupling.
- `T1` Tests rerun-stable/order-independent; isolate artifacts in temp roots; never share mutable `out/**`.
- `T2` Contract-first proof style: prefer CLI/artifact black-box checks; use internals only when boundary cannot encode invariant.
- `T3` Every invariant gets dual lanes: one pass lane + one typed fail lane.
- `T4` Evidence standard: "done" requires executable artifacts + invariant coverage; prose/logs are non-evidence.
- `T5` Bugfix protocol fixed: reproduce -> failing test -> patch -> `mise run fast` -> `mise run ci` (+ replay/schema proof if boundary changed).
- `T6` Goldens are contractual bytes; drift/missing fails; no test self-heal/auto-regenerate.
- `T7` Compile XOR proof required: success lane (`prog.py+contract.json`, no `compile_error.json`) and inverse fail lane.
- `T8` Boundary-byte edits (`trace|final|hash|order|clock|cache`) require deterministic rerun x3; include hashseed-variation where relevant.
- `T9` Replay-affecting edits must extend replay parity tests, including real task-level replay guard execution lanes.
- `T10` Eval anti-fraud tests required: all declared rows execute or typed-return unsupported; no silent skip/default winner.
- `T11` Fail-closed config tests required: unknown provider/cache/variant/plan/path/flag typed-fail early.
- `T12` CLI parse tests required: parser type errors and invalid scalar values emit typed stderr envelope + correct exit-code lane (no raw usage dumps).
- `T13` Dataset integrity tests required: explicit dataset ingress, required prompt key semantics, duplicate `task_id` rejection, anti-tautology guards.
- `T14` Resume/report integrity tests required: seq drift, duplicate terminals, corrupt NDJSON must fail integrity/code2.
- `T15` Ordering claims require explicit permutation + tie-break tests; incidental order coverage is not proof.
- `T16` Metrics/taxonomy tests required: required key set, single-label `fail_tag`, explicit `NO_CITE`, exact persisted `acc` (no jitter in evidence fields).
- `T17` Pointer/projection tests required: resolvability + non-destructive projection + payload split (`custom data/details` vs tiny hint <=120 chars).
- `T18` Optional capability tests required: default-off typed unsupported lane plus enabled lane.
- `T19` Merge blockers: op/order/id drift, replay drift, schema strictness drift, pointer loss/non-resolve, stdout pollution, tool-surface growth, truncation/redaction drift.
- `T20` Flake triage is fail-closed: pin env, rerun x3, replay-check; unresolved flakes stay red.
- `T21` Test names/docstrings encode invariant IDs/semantics, not implementation trivia.
